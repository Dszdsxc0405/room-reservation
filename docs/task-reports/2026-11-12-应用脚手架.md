3. 通过 Vue 官方 `create-vue@3.24.0` 生成 `web/`，采用 Vue 3、Vite、TypeScript 和 Vue Router；保留占位首页与根路由。初次依赖审计发现 ESLint 工具链的中危依赖，调整为 Oxlint 后，`npm ci` 审计结果为 0 项漏洞。依赖由 `package-lock.json` 固定。
4. 增加[数据库配置示例](../../config/application-db.example.properties)及忽略规则。本容器的开发库和本地测试库连接配置分别保存在仓库外的 `/opt/room-reservation/secrets/application-rr-dev.properties`、`application-rr-local-test.properties`，权限为 `0600`；文件中的真实密码未写入仓库或本记录。此次没有更改容器系统包或环境变量。
