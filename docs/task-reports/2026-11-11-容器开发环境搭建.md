为当前命令路径建立 `/usr/local/bin` 软链接：`java`、`javac`、`jar`、`mvn`、`node`、`npm`、`npx`、`corepack`，目标均指向上述固定版本的 `bin` 文件。没有覆盖已有同名文件；未设置 `JAVA_HOME` 或修改 `PATH`。

安装时实际使用 `curl -fL` 下载上述固定版本归档及校验文件；JDK 因单连接过慢改为同一 URL 的 HTTP Range 分段下载，合并并核对完整文件哈希。校验通过后执行的解压及入口命令为：

```bash
mkdir -p /opt/room-reservation/toolchains
tar -xzf /tmp/room-reservation-dev-env-20261111/temurin-jdk21-verified.tar.gz -C /opt/room-reservation/toolchains --no-same-owner
tar -xzf /tmp/room-reservation-dev-env-20261111/apache-maven-3.9.16-bin.tar.gz -C /opt/room-reservation/toolchains --no-same-owner
```

## 3. 独立 PostgreSQL 开发实例

- 使用已有 PostgreSQL 15.18 服务端程序和现有 `postgres` 系统账号，**没有启动系统的 `15/main` 集群**。以 `runuser -u postgres` 创建 `/var/lib/postgresql/room-reservation-dev`，在其 `data` 子目录运行 `initdb --auth-local=peer --auth-host=scram-sha-256 --encoding=UTF8 --locale=C.UTF-8`。
- 在该实例的 `postgresql.conf` 中配置 `listen_addresses = '127.0.0.1'`、`port = 55432`、`unix_socket_directories = '/var/lib/postgresql/room-reservation-dev'`；用该实例的 `pg_ctl -D ... -l /var/lib/postgresql/room-reservation-dev/server.log start` 启动。此进程不是系统服务，不会随容器重建自动恢复。
- 建立 `rr_dev` 和 `rr_local_test` 两个数据库及同名账号。每库撤销 `PUBLIC` 的 `CONNECT` 权限，仅授予所属账号。独立随机密码及 libpq `passfile` 分别保存在 `/opt/room-reservation/secrets/rr_dev.*` 与 `rr_local_test.*`，目录权限 `0700`、文件权限 `0600`；本记录不包含密码。
- 使用 `psql` 的 `passfile=` 连接参数验证：`rr_dev → rr_dev`、`rr_local_test → rr_local_test` 成功，返回端口 55432；两种交叉连接均被拒绝。未建立业务表、运行迁移或种子数据。开发和测试库虽各自隔离，仍共享这个本地 PostgreSQL 实例。

开发库连接检查命令如下；本地测试库使用相应的 `rr_local_test` 名称和 `passfile` 路径：

```sh
psql -d 'host=127.0.0.1 port=55432 dbname=rr_dev user=rr_dev passfile=/opt/room-reservation/secrets/rr_dev.pgpass' -c 'SELECT current_user, current_database(), inet_server_port();'
```

开发实例的手动管理命令（需由有权限的执行者在此容器运行）：

```sh
runuser -u postgres -- /usr/lib/postgresql/15/bin/pg_ctl -D /var/lib/postgresql/room-reservation-dev/data status
runuser -u postgres -- /usr/lib/postgresql/15/bin/pg_ctl -D /var/lib/postgresql/room-reservation-dev/data -l /var/lib/postgresql/room-reservation-dev/server.log start
runuser -u postgres -- /usr/lib/postgresql/15/bin/pg_ctl -D /var/lib/postgresql/room-reservation-dev/data stop
```
