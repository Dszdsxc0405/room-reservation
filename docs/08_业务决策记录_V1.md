| Q-14/15 | 提醒失败不阻止超时取消；只有真正超时未签到记违约，其他原因取消不记。预约终止只用“取消”状态。学生可查看本人违约记录。 | BP-02 |

| 单座位注销 | 取消该座位冲突的未来个人预约；已签到正在使用的个人预约可用到原定结束；整室批准和待审申请均保留，告知该座位不可用。 | BP-03/06 |
| Q-18/19 | 管理查看含预约量、取消数、签到量、未签到违约量和签到率，全部按预约使用日归属。预约量含后来取消的预约，取消数单列；签到率仅计需要签到且结果已确定的预约，管理/维修/审批取消不入分母，超时未签到计入。个人详情仅获授权教室管理员和系统管理员可见。 | BP-03 |
| Q-05/20 | 调低个人预约时长上限保留旧预约，新提交按新上限；撤销审批权限后由当前有权限者处理待办。系统管理员及获授权教室管理员可设置相应教室开放时间；仅系统管理员可授撤管理员角色和教室授权，不得给自己新增权限。 | BP-05/06 |
| 整室上限变更 | 调低整室时长上限后，已获批旧安排保留；待审申请按新上限重验，超出者不得继续获批；新提交按新上限校验。 | BP-05/06 |
| Q-10/22 | 已登录学生可申请本院系及全校教室，教职工可申请任意教室；用途必填，须在开放时间内，按自然日最多提前 3 天。整室时长上限独立配置，初始 8 小时；该教室管理员初审、系统管理员终审。 | BP-06 |
| 整室已开始 | 整室申请所选使用时段已经开始时，提交直接拒绝，不进入待审。 | BP-06 |
| Q-23 | 每级审批收到待办后满 48 小时未处理，或到使用开始仍未终审通过，自动撤销整笔申请并通知。申请人仅在终审通过前可撤回。 | BP-06 |
| Q-24 | 重叠整室申请可同时待审，首笔获批后第二笔终审自动驳回。教室报修提交时停止新整室申请、撤销未来待审申请、取消未来批准并通知；座位报修不取消整室安排，但须提示故障座位不可用。 | BP-06/07 |
| 并发先后 | 整室终审与教室报修或关闭计划同时发生时，按先完成的操作处理：先终审则后续报修/关闭取消批准；先报修/关闭则终审不能通过。 | BP-03/05/06/07 |
| 整室取消 | 整室批准后来取消，不自动恢复此前因此取消的个人预约；教室报修在维修前撤单，也不恢复因此取消的整室批准或待审申请，可重新申请。 | BP-01/06/07 |
| Q-02/12/25 | 学生或管理员可报修教室或座位，教室管理员派单、验收，维修员维修。报修提交即分别限制全室座位或故障座位新约，取消范围内未来个人预约并通知；已开始但尚未签到的预约立即取消且不记未签到违约，已签到正在使用的座位预约或整室安排可用到结束，之后才能进入维修中。 | BP-07 |
| Q-26～28 | 进入维修中满 72 小时未完工，通知系统管理员，原维修员继续负责；验收失败继续限制并重新派工，再次进入维修中重新计时。报修人只可在维修开始前撤单，已取消预约不自动恢复。一个资源有未结束工单时不得重复报修；验收通过后由原报修人评价。 | BP-07 |
