# BP-06 整教室申请、审批与结果生效：分析候选 V0

> 状态：主线及 AC-17～19/29 已获认可；Q-01/10/22～24 与申请人撤回规则已决定。依据：[课程任务书](Pj-任务书.pdf)第 1–2 页。

## 1. 边界与主线

起点为已登录学生或教职工希望在指定时段使用整间教室。主线：选择可申请教室、日期与起止时间并填写用途 → 系统核验身份与申请范围后提交 → 该教室管理员初审 → 系统管理员终审 → 通过则在该教室时段阻止新的个人座位预约并记录来源 → 申请人查看结果。学生可申请本院系及全校教室，教职工可申请任意教室；申请须在开放时间内，按学校本地自然日最多提前 3 天申请，单次整室时长上限独立配置，初始为 8 小时。其他结果包括驳回和超时自动撤销；每级收到待办后 48 小时未处理即撤销整笔申请，不留下本申请限制。最终通过时自动取消冲突的未来个人预约并发站内消息，不记未签到违约（Q-01/15/22/23）。

| 分支/先后顺序 | 已知结果或 Q |
|---|---|
| 未登录、学生申请非本院系的院系教室、未填写用途、超过整室时长上限或不在开放时间内 | 不能提交有效申请（Q-22） |
| 待审批时有人预约个人座位 | 待审批不占座（R-15），学生仍可按其他规则预约；后来获批时取消冲突预约并通知，不记未签到违约（Q-01/15） |
| 先获批，再来个人预约 | 个人预约不得成功（R-03） |
| 先有个人预约，后来审批到“通过” | 允许通过，自动取消冲突的未来个人预约并通知学生，不记未签到违约（Q-01/15） |
| 审批驳回、超时撤销 | 每级从收到待办起计时，48 小时未处理则自动撤销整笔申请；不留下该申请的整室限制（Q-23） |
| 同一教室重叠的两笔待审整室申请 | 可同时待审；第一笔获批后，第二笔终审时自动驳回并发站内消息给申请人（Q-24） |
| 教室工单进入维修中 | 维修期间不能提交该时段新整室申请；已提交的重叠待审申请自动撤销并通知申请人；已获批的重叠整室安排取消并通知申请人（Q-24） |
| 座位工单进入维修中 | 仍可申请整室，但须提示故障座位不可用；已获批整室安排保留 |
| 申请人主动撤回 | 仅在最终获批前可撤回；最终获批后不能主动撤回 |
| 已获批整室安排后来被取消 | 此前因获批而取消的个人预约不自动恢复；学生可按现行规则重新预约 |
| 审批人的权限在其处理待办前被撤销 | 原审批人不能继续审批；待办改由当前有权限者处理（Q-05） |
| 管理员保存未来关闭教室计划，覆盖整室安排 | 保存计划时取消生效后冲突的已获批整室安排；未终审通过的申请无论处于哪一级均立即撤销；均发站内消息给申请人。生效前的安排保留 |
| 管理员缩短未来开放时间 | 与关闭教室相同，保存计划时处理生效后冲突的整室批准和待审申请 |
| 管理员注销单个座位 | 已获批整室安排和待审整室申请均保留，告知该座位不可用 |
| 到使用开始仍未终审通过 | 自动撤销整笔申请并发站内消息给申请人 |

## 2. 事实、事件与规则

申请人、教室、时间区间、申请、各级审批记录及截止时点是关键事实。事件包括申请提交、两级审批、最终通过、驳回、超时撤销、申请人在终审前撤回、维修导致撤销/取消。R-11：M2 有权限门槛、申请提交、多级审批通过/驳回、超时自动撤销；R-03：最终批准影响整室座位可约性，驳回/超时后回滚其影响；R-05：M2 写入来源可追溯。
