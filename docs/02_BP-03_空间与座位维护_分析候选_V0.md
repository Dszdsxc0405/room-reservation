# BP-03 管理员维护自习室与座位（含管理查看）：分析候选 V0

> 状态：维护主线及 AC-11～13 已获认可；原 BP-04 的管理查看并入本流程，Q-18/19 已决定。依据：[课程任务书](Pj-任务书.pdf)附件 1，第 5–6 页。主数据归属仍待六人讨论。

## 1. 边界、主线与分支

起点为管理员需要登记、注销或调整一个自习室/座位；终点为登记信息及可用性按权限生效，并可供 BP-01 查询与预约判断。主线：管理员选定教室或座位 → 核对管理权限与唯一编号 → 修改登记、归属或可用性 → 系统保存并可追溯该变更。开放时间由 BP-05 统一设置（Q-21）。

关键分支：新增校级/院系自习室；登记或注销座位；修改插座标记；临时停用或恢复；有查看权限的管理员查询预约记录和使用统计，以供策略调整。计划性变更碰到未来有效预约时，按 Q-04 自动取消冲突预约并通知学生；按 Q-15 不记未签到违约。变更可立即或在指定未来时间生效；预设未来关闭时，保存计划即取消冲突预约并通知（Q-17）。

## 2. 事实、事件与规则

自习室有归属（全校/院系）、可用性；座位有唯一编号、所属教室、可用性和特殊标记。开放时间的权威配置在 BP-05。登记/注销/停用/恢复是本 BP 事件；注销后须保留历史预约和管理记录，按原权限查询。教室管理员只能维护明确授权的教室及座位，系统管理员可管理全部（Q-16）。

沿用 R-02；R-08：管理员按授权范围管理自习室与座位的登记、注销和可用性；开放时间由 BP-05 配置。R-09：授权管理员查看预约与使用情况。来源：任务书附件 1，第 5 页及用户 Q-16/21 决定。
