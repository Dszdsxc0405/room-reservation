# BP-03 管理员维护自习室与座位（含管理查看）V1

> 状态：主线及修订后的 AC-11～14 已获认可；原 BP-04 的管理查看并入本流程。依据：[课程任务书](Pj-任务书.pdf)附件 1，第 5–6 页。主数据由公共层 D 负责，见[分工决定](12_六人分工与数据归属_V1.md)。

## 1. 边界、主线与分支

起点为管理员需要登记、注销或调整一个自习室/座位；终点为登记信息及可用性按权限生效，并可供 BP-01 查询与预约判断。主线：管理员选定教室或座位 → 核对管理权限与唯一编号 → 修改登记、归属或可用性 → 系统保存并可追溯该变更。开放时间由 BP-05 统一设置（Q-21）。

关键分支：新增校级/院系自习室；登记或注销座位；修改插座标记；临时停用或恢复；有查看权限的管理员查询预约记录和使用统计，以供策略调整。变更可立即或在指定未来时间生效；生效前预约保留。保存关闭教室计划时，立即取消生效后冲突的未来个人座位预约和已获批整室安排、撤销待审整室申请，均发站内消息；立即关闭时，已签到正在使用的个人预约及正在使用的整室安排可用到原定结束；已开始但尚未签到的个人预约保留到原签到截止时点，期间可按原规则签到并使用到原定结束，逾期未签到按通常规则记违约。撤销关闭计划不自动恢复此前取消的安排，可重新预约或申请。注销座位取消该座位冲突的未来个人预约，已签到正在使用的个人预约可用到原定结束；已开始但尚未签到的个人预约按上述原签到截止时点、签到和违约规则处理；已有整室批准和待审整室申请均保留并告知该座位不可用。上述取消不记未签到违约。

## 2. 事实、事件与规则

自习室有归属（全校/院系）、可用性；座位有唯一编号、所属教室、可用性和特殊标记。开放时间的权威配置在 BP-05。登记/注销/停用/恢复是本 BP 事件；注销后须保留历史预约和管理记录，按原权限查询。教室管理员只能维护明确授权的教室及座位，系统管理员可管理全部（Q-16）；开放教室须始终有至少一名获授权教室管理员。

沿用 R-02；R-08：管理员按授权范围管理自习室与座位的登记、注销和可用性；开放时间由 BP-05 配置。R-09：授权管理员查看预约与使用情况。来源：任务书附件 1，第 5 页及用户 Q-16/21 决定。
