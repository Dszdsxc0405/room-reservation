# BP-05 系统管理员配置规则与权限：分析候选 V0

> 状态：主线及 AC-15/16/36 已获认可；Q-05/17/20/21 核心规则已决定。依据：[课程任务书](Pj-任务书.pdf)附件 1，第 5 页及 D 公共层说明。

## 1. 边界与主线

起点为有管理权限的人员希望调整系统参数、教室开放时间、角色或权限；终点为配置保存并按约定时点生效，关联业务流程依新的规则判断。候选主线：查看当前配置 → 调整个人或整室预约时长上限、开放时间或权限配置 → 核验管理权限和参数合法性 → 保存与追溯 → 受影响的 BP 使用新配置。整室上限独立配置，初始 8 小时（Q-22）。系统管理员可管理全部配置；教室管理员可配置其获授权教室的开放时间（Q-20）。

分支：改变预约上限、角色权限或教室开放时间；改变现有学生或管理员的权限；配置与已生效预约或在途审批冲突。时长上限调整保留旧预约，新提交按新上限；审批权限撤销后，原审批人不能继续处理待办，由当前有权限者处理（Q-05）。仅系统管理员可授予或撤销管理员角色及教室授权，且不能给自己新增权限（Q-20）。教室与座位主数据、可用性由 BP-03 维护；开放时间只由本 BP 配置（Q-21）。开放时间变更可立即或在指定未来时间生效；缩短开放时间时保存计划即取消冲突预约并通知（Q-04/17）。

## 2. 事实、能力与故事

配置项、角色、权限、用户角色关系、变更人和生效时间是候选业务事实。R-10：系统管理员可管理配置、角色及权限，并可设定可用自习室/开放时间。R-01 的单次最长时长“可调”在本流程落地。RBAC、空间主数据和操作审计属于任务书 D 的范围线索，但具体 D 归属由六人决定。

| CAP | UC | US |
|---|---|---|
| CAP-09 管理配置及生效范围 | UC-11 系统管理员调整预约规则及开放时间 | US-11 调整个人/整室预约时长上限或教室开放时间 |
| CAP-10 管理角色权限并审计变更 | UC-12 系统管理员配置角色权限 | US-12 维护角色与其可操作范围 |

| AC | 前提 / 操作 / 结果 |
|---|---|
| AC-15 | 系统管理员将单次时长上限改为 3 小时并使其生效；已生效的 4 小时旧预约保留，随后学生提交 4 小时的新预约被拒绝、3 小时在其他条件满足时可成功（R-01/R-10/Q-05） |
| AC-16 | 系统管理员撤销某审批人的权限后，该人不能继续处理已收到但未完成的申请，改由当前有权限者处理；教室管理员不能授予管理员角色或教室授权，系统管理员不能给自己新增权限；其他新的管理操作按当前授权判断（R-10/Q-05/20） |
| AC-36 | 系统管理员或获授权教室的管理员缩短该教室未来时段的开放时间；保存配置计划时立即取消冲突的未来预约并通知学生、不记未签到违约；受影响时段不能再被新预约选中（Q-04/15/17/20/21） |
